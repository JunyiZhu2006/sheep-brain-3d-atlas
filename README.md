# Sheep brain 3D atlas

An interactive 3D atlas of the sheep brain, built on the Turone sheep MRI atlas.

The page is password-protected. It is encrypted (AES-256-GCM, key derived from the password with PBKDF2-SHA256, 600,000 iterations) and decrypted locally in your browser. Ask the author for the password.

Open it at the GitHub Pages address of this repository. It needs a recent Chrome, Safari, Edge or Firefox.

## Data source

MRI geometry: Turone Sheep Brain Template and Atlas v2 (CC BY 4.0), doi:[10.5281/zenodo.10730961](https://doi.org/10.5281/zenodo.10730961).
